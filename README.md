# CPU Scheduler

> A C++ implementation project for understanding and experimenting with CPU scheduling algorithms.

## Overview

This project demonstrates core operating-system scheduling concepts through programmatic implementations of CPU scheduling techniques. It is intended as a learning and academic project focused on algorithmic thinking, process scheduling, and performance metrics.

## Concepts

- Process scheduling
- CPU burst and waiting time
- Turnaround time
- Response time
- Scheduling order and execution flow

## Tech Stack

- C++
- Standard input/output
- Algorithmic problem solving

## Why This Project

CPU scheduling is a foundational operating-systems problem. Implementing the algorithms from scratch provides practical experience with process management concepts and algorithm analysis.
